# AI-assisted development log

Record the AI tools used and the prompts that materially influenced the implementation. Keep this file truthful and update it as work proceeds.

## Example prompts
- “Design a beginner-friendly employee salary CRUD API using FastAPI, SQLAlchemy, and SQLite.”
- “Review the salary analytics query to ensure different currencies are not summed together.”
- “Suggest deterministic pytest cases for duplicate employee codes, negative salaries, pagination, and CSV export.”
- “Review the React API error states and employee form validation.”

## Human verification
- Run tests locally and record the output.
- Review all generated code and understand the endpoint/data model decisions.
- Check the seeded row count and test CSV export.
- Do not claim deployment or tests passed until they have actually been run.
